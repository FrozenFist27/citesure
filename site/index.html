How it works

Four steps, one honest behaviour

Every claim is backed by a verbatim quote that code — not trust — checks against the source PDF.

1

Reads your PDFs

Keeps headings, page numbers and tables while parsing — so chunks know where they came from.

2

Finds the passages

Keyword + semantic search together, then re-ranks the candidates for the question at hand.

3

Writes with proof

A short answer where every sentence quotes the source verbatim — checked character-for-character by code.

4

Stays honest

Declines or asks one clarifying question when the documents don’t cover the question. No guessing.

FAQ

Questions clients ask first

Can it use my documents?

Yes — PDFs today; DOCX/HTML in the Standard tier. You must have the rights to the documents.

Does it ever make things up?

Every quote is checked character-for-character against the source; uncovered questions are declined. The eval report shows how often it is right — no system is perfect, and the report shows where it fails.

Where does my data go?

Embeddings run locally; only the top passages for each question are sent to the LLM provider you choose. Self-hosting available.

What does it cost to run?

See the measured cost per question in the eval report; ingest is free (local models). Cost figures on this site stay placeholders until a measured run produces them.

Which LLMs?

Claude by default; Gemini supported; others via the provider interface.

Scanned PDFs?

Not in this demo (no OCR); can be added per project.
